# User Test Plan (20–30 minutes total) – do this BEFORE the demo

The brief's rubric asks for "unit testing, user testing". Unit tests are done (99). User testing must be done by YOU with real people – write down only what really happens.

**Who:** 3–5 people (classmates/friends/family), at least one who has never seen the app. Install the APK or use Expo Go on your phone and hand it over.
**Say:** "Please think aloud. I'm testing the app, not you." Don't help unless they are stuck for 30 seconds.

## After the tasks (rate 1 = strongly disagree … 5 = strongly agree)
1. The app was easy to use. 2. I always knew where I was in the app. 3. Text and buttons were easy to read and tap. 4. I would trust this app with my walking data. What confused you? What would you change?

## Write-up (put 2–3 lines in the report, Testing Strategy)
"I tested with N participants. X/N completed all tasks unaided; average ease rating Y/5. Main issue: ___ → I changed ___."
If you change something because of feedback, say so – that is the best evidence of a real debugging/UX process.

## TalkBack mini-test (5 minutes, Android)
Settings → Accessibility → TalkBack on. Swipe through Sign in, My Walks, Record, Walk detail, Profile. Note anything unlabeled or read in a confusing order, and mention one finding in the Accessibility bullet.
